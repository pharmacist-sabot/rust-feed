# GitGuardian พอร์ต Secrets Detection Engine จาก Python สู่ Rust ได้ความเร็วเพิ่มขึ้น 43x

> 📅 วันที่เผยแพร่: 2026-05-20

จุดเริ่มต้นของการเปลี่ยนผ่านจาก Python มาเป็น Rust ในเอนจินตรวจจับความลับอย่าง Tokenscanner ของ GitGuardian เกิดจากข้อจำกัดด้านความเร็วและการแจกจ่ายซอฟต์แวร์ เมื่อปริมาณข้อมูลที่ต้องสแกนเพิ่มขึ้นอย่างรวดเร็ว การทำงานของ Python เริ่มตอบสนองได้ไม่ทันใจ อีกทั้งการนำซอฟต์แวร์ไปติดตั้งในฝั่งลูกค้า (On-premise) ก็ทำได้ยากเพราะต้องคอยจัดการสภาพแวดล้อมและ Dependency ต่างๆ ทีมงาน GitGuardian จึงตัดสินใจพอร์ตระบบมาเป็น Rust เพื่อหวังผลเรื่องความเร็วและการคอมไพล์เป็นไฟล์ไบนารีเดี่ยวที่สามารถส่งมอบและเปิดใช้งานได้ทันทีโดยไม่ต้องพึ่งพารันไทม์ภายนอก

การเปลี่ยนภาษาไม่ได้มอบความเร็วที่เหนือชั้นให้ในทันที ทีมงาน GitGuardian เริ่มต้นด้วยการแปลงโค้ดแบบตรงไปตรงมาจาก Python เป็น Rust ซึ่งแม้จะช่วยลด Overhead ของ Interpreter ลงและได้ความเร็วเพิ่มขึ้นมาราว 4 ถึง 5 เท่า แต่ตัวเลขนี้ยังห่างไกลจากเป้าหมายในการสแกนประวัติข้อมูลย้อนหลัง (Historical scans) ปริมาณมหาศาลที่เคยต้องใช้เวลาหลายวัน ทีมงานจึงรู้ดีว่าการจะรีดประสิทธิภาพของ Rust ออกมาให้ถึงขีดสุด พวกเขาต้องขยับลงไปจัดการระบบในระดับที่ลึกกว่านั้น

การปรับแต่งในเฟสถัดมาจึงเน้นไปที่การควบคุมการจัดการหน่วยความจำและโครงสร้างข้อมูลภายในของ Rust อย่างละเอียด โดยลดการคัดลอกข้อมูลในหน่วยความจำที่ไม่จำเป็น (Zero-copy) และปรับแต่งกลไกการค้นหา Pattern ให้ทำงานได้เต็มประสิทธิภาพ ผลลัพธ์ที่ได้คือสามารถดันอัตราการประมวลผลในระดับเธรดเดี่ยว (Single-threaded) ให้ทะลุ 100 เมกะไบต์ต่อวินาทีได้สำเร็จ โดยที่ยังไม่ได้เริ่มเขียนโค้ดเพื่อประมวลผลแบบขนานเลยด้วยซ้ำ ส่งผลให้ประสิทธิภาพโดยรวมของเอนจินตัวนี้พุ่งสูงขึ้นถึง 43 เท่าจากระบบเดิมอย่างก้าวกระโดด

ความเร็วที่เพิ่มขึ้นนี้ไม่ได้แลกมาด้วยการลดทอนความสามารถในการทำงาน เพราะในระหว่างการปรับปรุงระบบ มีการเพิ่มกฎในการตรวจสอบสิทธิ์ (Detectors) ใหม่ๆ เข้าไปอีกกว่า 100 ตัว จนปัจจุบันระบบมีตัวตรวจจับรวมกันมากกว่า 600 รูปแบบแล้ว หากเป็นโครงสร้างระบบเดิม ยิ่งเราเพิ่มกฎในการสแกนมากเท่าไหร่ ความเร็วก็จะยิ่งตกลงเป็นเงาตามตัว แต่โครงสร้างใหม่บน Rust ช่วยให้ระบบสามารถสแกนหา secret ประเภทใหม่ๆ ได้มากมายโดยแทบไม่มีผลกระทบต่อความเร็วในการประมวลผลเลย

การปรับปรุงครั้งนี้ช่วยเปลี่ยนประสบการณ์ใช้งานของลูกค้าอย่างสิ้นเชิง งานสแกนขนาดใหญ่ที่เคยต้องรอนานหลายชั่วโมงถูกย่นระยะเวลาลงมาเหลือเพียงไม่กี่นาที ซึ่งถือว่าสำคัญมากสำหรับระบบความปลอดภัยยุคปัจจุบัน เนื่องจากสถิติชี้ว่าร้อยละ 28 ของการรั่วไหลไม่ได้เกิดขึ้นในซอร์สโค้ด แต่เกิดขึ้นในไฟล์แนบหรือเอกสารบนระบบจัดการทำงานร่วมกัน การมีเอนจินที่สแกนไฟล์ขนาดใหญ่เหล่านี้ได้อย่างรวดเร็วและแม่นยำด้วยภาษา Rust จึงกลายเป็นหัวใจสำคัญที่ช่วยปิดช่องโหว่ได้อย่างมีประสิทธิภาพ จนชื่อคลิปต้องมีคำว่า Thanks To Rust 🦀
