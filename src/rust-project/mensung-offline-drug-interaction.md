# MenSung สร้างแอปที่พร้อมไปทุกที่ด้วย Rust

> 📅 วันที่เผยแพร่: 2026-07-17

นานๆ จะเจอโปรเจคต์ที่เกี่ยวกับเภสัชสักที 😅 MenSung (Medical Shield) คือเครื่องมือตรวจสอบอันตรกิริยาระหว่างยาแบบออฟไลน์สำหรับบุคลากรทางการแพทย์ในพื้นที่ภัยพิบัติหรือค่ายผู้ลี้ภัย โดยมีโจทย์อยู่ว่า ระบบต้องทำงานได้บนเครื่องแล็ปท็อปเก่าอายุ 10-15 ปี (ระดับ Core 2 Duo, RAM 2-4GB) ไม่มีอินเทอร์เน็ต และไม่มี Database Server ตัวแอปจึงต้องการ Startup time ต่ำกว่า 100ms, ใช้แรมไม่เกิน 50MB และต้องมี Memory footprint ที่คาดเดาได้ ซึ่งการควบคุมทรัพยากรระดับ Low-level ของ Rust ทำได้แน่นอน 👏👏

MenSung เลือกใช้ Hexagonal Architecture ร่วมกับ Cargo Workspace เพื่อแยกขอบเขตการทำงานอย่างชัดเจน ทิศทางของ Dependency จะวิ่งเข้าหา mensung-domain เพียงทางเดียว ซึ่งภายใน Crate นี้จะมีเพียง Core Logic, Entity และกฎการคัดกรองยา โดยปราศจาก I/O, UI การใช้ Type System ของ Rust ช่วยให้สามารถควบคุมทิศทางของ Dependency ไม่ให้เกิดการเชื่อมโยงที่ซับซ้อน ทำให้การทดสอบ Domain Logic เป็นไปอย่างอิสระและจัดการง่ายขึ้น

จุดเด่นที่น่าสนใจคือการจัดการข้อมูลผ่าน mensung-db และ mensung-core ซึ่งทำงานกับไฟล์ฐานข้อมูลรูปแบบเฉพาะตัว (.men) โดยระบบจะเน้นการทำงานแบบ Zero-copy Access เพื่ออ่านข้อมูลบน Disk มาใช้โดยไม่ต้องทำการ Deserialize ซ้ำซ้อน ช่วยให้การตรวจสอบอันตรกิริยาระหว่างยาทำได้รวดเร็วภายในเวลาไม่ถึง 5ms ความสามารถในการจัดการ Lifetime ของ Rust ช่วยให้เข้าถึงข้อมูลในไฟล์ขนาดราว 10-27MB ได้โดยตรงอย่างปลอดภัย ไม่ต้องกังวลเรื่องหน่วยความจำรั่วไหลหรือ Overhead จาก Garbage Collector

ด้านการเชื่อมต่อเครือข่ายและความปลอดภัย มีการแยกโค้ดที่แตะต้องเน็ตเวิร์กออกไปอย่างเด็ดขาด โดยปล่อยให้เป็นหน้าที่ของ mensung-builder ในการดาวน์โหลดและแปลงข้อมูลยาจากแหล่งภายนอก เช่น DDInter หรือ openFDA เฉพาะตอนติดตั้งครั้งแรกเท่านั้น ส่วน mensung-client ที่ใช้งานจริงจะไม่มีการเรียกใช้ระบบเครือข่ายขณะตรวจสอบข้อมูลเลย

ตัวแอปถูกคอมไพล์เป็น Static Link Binary ขนาดไม่เกิน 10MB ทำให้สามารถคัดลอกไฟล์แอปและไฟล์ .men ไปรันบนเครื่องที่ออฟไลน์ได้อย่างสมบูรณ์ ช่วยลดความเสี่ยงด้านความเสถียรและตัดปัญหาเรื่องความปลอดภัยของข้อมูลผู้ป่วย ✍️ ส่วนตัวลองเทสแล้ว จะหา paracetamol ไม่เจอะนะครับ ต้องใช้ acetaminophen แทน 😅
